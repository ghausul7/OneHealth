# OneHealth Frontend

Presentation-ready frontend prototype for the OneHealth project.

## Stack
- React
- Vite
- Tailwind CSS
- React Router
- Lucide React icons

## Run
1. Open this folder in VS Code.
2. Open the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Routes
- `/` — Landing page
- `/patient` — Patient dashboard
- `/doctor` — Doctor dashboard
- `/admin` — Admin dashboard

This version uses mock data only. Backend/database integration can be added later.
